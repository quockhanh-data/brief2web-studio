# Deploy Guide

## GitHub Pages

1. Push cả `main` và branch dự án lên GitHub.
2. Vào `Settings` -> `Pages`.
3. Source: `Deploy from a branch`.
4. Chọn branch cần public.
5. Folder: `/root`.

## Đổi branch web đang public

Ví dụ chuyển từ trang tổng sang web Y-VOICE:

1. `Settings` -> `Pages`.
2. Branch: `yvoice-insight-hub`.
3. Folder: `/root`.
4. Save.

## Domain sau này

Khi có domain riêng, cấu hình `Custom domain` trong GitHub Pages hoặc copy toàn bộ file của branch đã chốt sang hosting chính.
