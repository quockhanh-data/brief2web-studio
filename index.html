Ý tưởng repo

Một repo tổng, nhiều nhánh demo theo từng đơn web.

`main` giữ trang giới thiệu dịch vụ. Các nhánh như `yvoice-insight-hub` giữ từng bản website riêng để khách xem, góp ý và chốt hướng thiết kế.

Dịch vụ

Làm nhanh bản tĩnh để khách thấy được web thật.

01

Website CLB, đội nhóm

Giới thiệu, hoạt động, tuyển thành viên, bài viết và liên hệ.

02

Landing page sự kiện

Thông tin chương trình, timeline, CTA đăng ký và bộ nhận diện riêng.

03

Trang tin, tập san

Bố cục magazine, danh mục nội dung, bài nổi bật và tìm kiếm cơ bản.

04

Portfolio cá nhân

Profile, dự án, năng lực, liên hệ và giao diện hợp ngành.

Quy trình

Từ brief đến link review.

  1. Nhận brief Nội dung, logo, màu sắc, web tham khảo, mục tiêu người xem.
  2. Dựng prototype HTML/CSS/JS tĩnh, responsive, có asset và bố cục thật.
  3. Review theo nhánh Mỗi đơn nằm ở một branch, dễ so sánh và không đụng bản tổng.
  4. Deploy Đẩy GitHub Pages hoặc chuyển sang hosting/domain chính.

yvoice-insight-hub

Website tĩnh Y-VOICE | Tiếng nói lý luận trẻ, thiết kế theo logo và bìa CLB.

git switch yvoice-insight-hub

Deploy

Main là dự án tổng. Nhánh riêng là web khách.

Khi cần cho khách xem, có thể deploy branch tương ứng qua GitHub Pages hoặc tạo repo riêng từ branch đã chốt.

git branch git switch yvoice-insight-hub git switch main
