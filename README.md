# Y-VOICE Insight Hub

Website tĩnh đặt thiết kế theo yêu cầu cho Insight Youth Voice Club.

## Điểm nổi bật

- Landing page nhận diện CLB Y-VOICE.
- Bố cục học thuật kết hợp phong cách trang tin online.
- Hero dùng bìa chính thức của CLB.
- Bảng tin mẫu có lọc chuyên mục và tìm kiếm.
- Responsive cho desktop và mobile.

## Cấu trúc

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
```

## Chạy thử

Mở `index.html` trực tiếp hoặc chạy server tĩnh:

```bash
python -m http.server 4173
```

Sau đó vào `http://127.0.0.1:4173`.

## Deploy GitHub Pages

1. Upload toàn bộ file ở thư mục này lên repo.
2. Vào `Settings` -> `Pages`.
3. Chọn `Deploy from a branch`.
4. Branch: `main`, folder: `/root`.

Tên repo gợi ý: `yvoice-insight-hub`.
